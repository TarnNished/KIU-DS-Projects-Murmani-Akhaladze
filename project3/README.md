##  Project Description

This project explores a student performance dataset using different data visualization techniques in Matplotlib and Seaborn. The goal was to understand which factors affect GPA and overall academic outcomes. The project is split into three main tasks:

1. **Task 1:** Basic Matplotlib visualizations (line plot, scatter plot, bar chart, histogram, boxplot, and subplots).  
2. **Task 2:** Seaborn-based statistical and relational plots such as violin plots, heatmaps, pairplots, and regression plots.  
3. **Task 3:** A complete visual “story” with research questions and a written insights section that explains patterns, findings, and recommendations.

The dataset includes academic behavior (study hours, attendance), lifestyle variables (sleep, part-time work), and academic metrics (previous GPA, scores, finals, etc.).

##  How to Run the Code

1. Make sure you have Python 3.10+ installed.  
2. Install required libraries:

```bash
pip install pandas numpy matplotlib seaborn
```

3. Place the file **student_performance.csv** in the same folder as the script or notebook.  
4. Run the script:

```bash
python task.py
```

All plots will display automatically as the program runs.

##  Brief Summary of Key Findings

Here are the main insights discovered through the visualizations:

- **Study hours and attendance** have a strong positive relationship with GPA and final grades. Students who study more and attend classes regularly generally perform much better.
- **Previous GPA** is one of the strongest predictors of **current GPA**. Students who started strong usually stay strong.
- **Sleep matters**: students with extremely low sleep hours tend to have weaker academic performance.
- **Majors and year levels differ**, with juniors and seniors performing slightly better than freshmen.
- **Part-time work** seems to reduce GPA slightly when work hours get too high.
- **Scholarship students** usually perform a bit better than non-scholarship students.

These patterns highlight that consistent study habits, good attendance, and balanced lifestyle choices all play major roles in academic success.
